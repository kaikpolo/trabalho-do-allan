
# 🎟️ Desafio 01 - Gerador de Ingresso para Conferência

Projeto desenvolvido para a disciplina de **Design e Desenvolvimento Frontend** (Curso de ADS).

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estruturação semântica e formulário de dados)
- **CSS3** (Flexbox, Variáveis CSS e Responsividade)
- **JavaScript** (Manipulação básica do DOM para pré-visualização do ingresso)

## 📌 Funcionalidades
- Carregamento instantâneo de avatar personalizado.
- Atualização em tempo real do nome e usuário do GitHub no bilhete.
- Layout responsivo adaptado para dispositivos móveis e desktop.
